# 报销材料管理系统 UI/UX 优化设计规格

日期：2026-05-21

## 1. 目标

把当前基础 CRUD 界面升级为现代企业 SaaS 风格的报销材料工作台。核心目标不是单纯美化，而是提高材料处理效率：记录行可直接进入详情、预览、编辑和上传材料，减少页面跳转。

## 2. 设计方向

采用“企业级材料工作台”信息架构和现代企业 SaaS 视觉风格。

- 左侧固定侧边栏承载主导航。
- 顶部栏显示页面标题、当前用户、角色和退出入口。
- 主内容区以工作台方式展示状态指标、筛选区和记录列表。
- 点击记录行打开右侧抽屉，不离开当前列表上下文。
- 点击附件进入全屏材料预览器。

## 3. 全局框架

### 3.1 侧边栏

侧边栏替代当前顶部裸链接导航。

导航项按角色裁剪：

- 员工：我的报销。
- 管理员：我的报销、报销工作台、批次管理、用户管理、分类管理。

当前页面必须有明确高亮状态。导航图标使用一致的 SVG 图标体系，不使用 emoji。

### 3.2 顶部栏

顶部栏包含：

- 当前页面标题。
- 页面说明或当前筛选上下文。
- 当前用户名称。
- 角色标签。
- 退出登录入口。

### 3.3 主内容区

页面统一使用浅灰蓝背景，内容卡片使用白色表面、细边框和轻阴影。页面外边距 24px，卡片内边距 16–24px。

## 4. 报销工作台

工作台页面替代裸表格。

### 4.1 顶部指标卡

显示关键状态：

- 草稿数。
- 已提交数。
- 已归档数。
- 材料不完整数。

指标卡用于快速建立整体状态，不做复杂图表。

### 4.2 筛选区

员工端筛选：

- 状态。
- 分类。
- 时间范围。
- 关键词。

管理员端筛选：

- 员工。
- 分类。
- 状态。
- 时间范围。
- 关键词。

筛选区使用紧凑但清晰的表单布局，支持重置。

### 4.3 记录列表

每行展示：

- 金额。
- 员工和部门（管理员端）。
- 用途分类。
- 用途说明。
- 支付时间。
- 状态。
- 材料完整度。
- 关键操作。

整行可点击打开右侧抽屉。行内只保留少量高频操作，避免按钮堆叠。

## 5. 右侧详情抽屉

点击任意记录行打开右侧抽屉，宽度 520–640px。

抽屉分为四块：

1. 记录摘要。
2. 字段编辑区。
3. 材料区。
4. 底部固定操作栏。

### 5.1 记录摘要

摘要区突出金额、状态、员工、部门、分类、支付时间和材料完整度。

状态标签统一：

- 草稿：灰/琥珀。
- 已提交：蓝。
- 已归档：绿。
- 材料缺失：红。

### 5.2 字段编辑区

状态决定可编辑性：

- 草稿：员工可编辑金额、分类、用途说明、支付时间和附件。
- 已提交：员工只读；管理员可写备注、加入批次。
- 已归档：全部只读。

字段错误展示在字段附近，不能只在顶部提示。

### 5.3 材料区

材料分三组：

- 支付凭证（必填）。
- 订单截图（选填）。
- 发票（选填）。

每个附件展示：

- 文件类型。
- 文件名。
- 上传时间。
- 大小。
- 预览。
- 下载。
- 删除（仅草稿）。

空状态：

- 支付凭证为空时显示红色提示“提交前必须上传支付凭证”。
- 可选材料为空时显示中性说明“未上传”。

### 5.4 底部固定操作栏

操作随状态变化：

- 草稿：保存草稿、提交。
- 已提交：加入批次、保存备注。
- 已归档：只读提示、下载材料。

所有异步操作必须有 loading 状态和成功/失败反馈。

## 6. 全屏材料预览器

点击附件预览进入全屏 overlay。

### 6.1 顶部栏

包含：

- 文件名。
- 文件类型标签。
- 下载按钮。
- 关闭按钮。

### 6.2 预览区

- 图片：适配屏幕，支持缩放查看。
- PDF：内嵌浏览器 PDF 预览。
- 不支持类型：显示下载卡片。

### 6.3 切换与缩略图

同一条报销记录内的附件组成预览集合。

- 支持上一份/下一份。
- 底部显示缩略图条。
- 当前附件高亮。
- 缩略图带材料类型标签。

关闭预览器后回到原抽屉，并保持抽屉状态。

## 7. 视觉系统

### 7.1 色彩

使用语义色 token，不在组件中分散硬编码颜色。

建议 token：

- primary：企业蓝。
- success：归档/完整材料绿色。
- warning：草稿/待处理琥珀。
- danger：材料缺失/删除红。
- surface：白色卡片。
- background：浅灰蓝页面背景。
- text-primary：深色正文。
- text-secondary：中性辅助文字。
- border：浅色边框。

### 7.2 字体

优先使用系统字体，保证中文清晰和加载稳定。

- 页面标题：24px / 600。
- 区块标题：18px / 600。
- 正文：14px。
- 辅助信息：12–13px。
- 金额：tabular number。

### 7.3 间距

使用 4/8px spacing rhythm。

- 页面外边距：24px。
- 卡片内边距：16–24px。
- 表单项间距：16px。
- 表格行高：48–56px。
- 抽屉区块间距：24px。
- 全屏预览器顶部栏：56px。

## 8. 组件边界

新增或重构以下组件：

- `AppShell`：侧边栏、顶栏、内容区。
- `StatusTag`：统一状态标签。
- `MetricCard`：工作台指标卡。
- `MaterialCompleteness`：材料完整度展示。
- `RecordDrawer`：右侧详情抽屉。
- `MaterialList`：附件分组列表。
- `MaterialPreviewer`：全屏材料预览器。
- `EmptyState`：统一空状态。
- `ConfirmAction`：删除、归档等危险操作确认。

每个组件保持单一职责，不把工作台逻辑全部堆在页面文件里。

## 9. 交互与反馈

- 所有可点击项有 hover、focus、active 状态。
- 所有表单字段有可见 label。
- 所有异步按钮有 loading 状态。
- 上传成功后材料区即时刷新。
- 删除附件前必须确认。
- 归档批次前必须确认。
- 错误提示必须说明原因和恢复方式。
- 空列表必须显示说明和主操作按钮。

## 10. 响应式要求

第一阶段以桌面 Web 为主，但不能在窄屏完全破坏：

- ≥1024px：侧边栏 + 内容区 + 抽屉。
- 768–1023px：侧边栏可折叠，抽屉宽度降低。
- <768px：抽屉改为全屏面板，列表列数减少。

不允许出现横向滚动作为主要交互方式。

## 11. 验收标准

### 员工端

- 员工进入“我的报销”能看到状态指标、筛选和记录列表。
- 点击记录行打开右侧抽屉。
- 草稿可在抽屉内编辑字段、上传/删除附件、提交。
- 已提交记录只读，可预览和下载附件。
- 点击附件可进入全屏材料预览器。

### 管理端

- 管理员进入“报销工作台”能按员工、分类、状态、时间筛选。
- 点击记录行打开抽屉。
- 已提交记录可写备注、加入批次、预览附件。
- 已归档记录只读。
- 批次页延续同一视觉系统，导出和归档操作有明确反馈。

### 视觉与可用性

- 不再出现裸 HTML 风格表格和按钮。
- 页面具备统一侧边栏、顶栏、卡片、状态标签和空状态。
- 关键操作具备 loading、成功和失败反馈。
- 键盘 focus 状态可见。
- 前端测试和构建通过。

## 12. 非目标

本轮不做：

- 审批流。
- 付款管理。
- OCR。
- 外部财务系统对接。
- 移动 App。
- 复杂 BI 图表。
- 自定义品牌 Logo 设计。
